## 一、统一规范（所有场景、动作都要遵守）

| 项目 | 规范 |
|---|---|
| 分辨率 / 帧率 | 2560×1440，24fps |
| 循环片段 | 8 秒，共 192 帧，第 193 帧 = 第 1 帧，首尾无缝 |
| 一次性片段 | 长度不固定（建议 2–5 秒），从「中立姿势」开始，在「中立姿势」结束 |
| 中立姿势 | 站立待机姿势（手臂下垂、袖子下垂、轻微歪头），所有片段都从这里起止，方便 Wallpaper Engine 无缝切换 |
| 镜头风格 | 斜俯视正交镜头（等距小场景），室内用「去掉两面墙的剖面小屋」 |
| 引擎 | Blender 5.2，EEVEE，64 采样，先用无界面模式（`-b`）运行 |
| 袖口补偿 | 所有手臂动作都要沿用 `animate_loop.py` 里的袖口反向补偿，否则袖子会横到腰前 |
| 帽子 | 躺下、趴桌时帽子容易穿模，需要时摘下来，换成场景里的道具（衣帽钩或桌角） |
| 人物版权 | 伊蕾娜出自《魔女之旅》，只能用于非商业课程演示；场景和道具全部用原创设计 |

## 二、场景清单

### 场景 1：共生岛（户外）· 休息与日常　✅ v4 已完成

- **用途**：空闲时间、休息、提醒、完成任务时的主画面
- **光照版本**：早 / 午 / 夜三套 ✅；深夜熄灯版 ⬜（23:00 后灯笼、窗户大部分熄灭）
- **元素**

| 类别 | 内容 | 状态 |
|---|---|---|
| 地形 | 按效果图轮廓的主岛、起伏草地、15000 簇草、3200 朵小花、岸边岩石和青苔 | ✅ |
| 建筑 | 半木结构木屋（大窗、藤蔓屋檐、烟囱炊烟）、L 形门廊、台阶 | ✅ |
| 水边 | 码头 + 小船、睡莲、芦苇和香蒲、4 只鸭子、海浪泡沫 | ✅ |
| 道路 | 石板路（主路、后路、通桥的路）、路边石子、石阶 | ✅ |
| 中心区 | 篝火（石圈、木柴、火苗、火星、三脚架吊锅、原木凳）、野餐桌（提灯、书、杯子、花瓶）、鸟屋、树桩 | ✅ |
| 右侧 | 小溪、拱桥、瀑布、水雾 | ✅ |
| 植物 | 圆冠树 8 棵、灌木、花丛 24 处、门廊前 3 个花箱 | ✅ |
| 灯光 | 路边灯笼 10 盏、门廊吊灯、壁灯、码头灯、窗光、暖色补光、月光补光 | ✅ |
| 远景 | 海平线、对岸小岛、亮灯小屋、月亮、星星、水面碎光 | ✅ |
| 氛围 | 萤火虫、体积雾、光晕 | ✅ |
| 待补 | 草地中右侧偏空（可加晾衣绳挂小灯或秋千）；早 / 午两个版本还没逐帧检查 | ⬜ |

### 场景 2：木屋室内 · 自习与睡觉　⬜ P0

- **用途**：待办里的学习任务（背单词、写实验报告）、深夜睡觉
- **镜头**：和岛屿同风格的斜俯视剖面小屋，这样从外面看到的窗光和室内能对上
- **光照版本**：清晨（窗帘缝的晨光，拉开窗帘后变亮）、白天（窗外日光）、夜晚（台灯 + 壁炉）、深夜（只剩床头小夜灯 + 窗外月光）
- **元素**

| 区域 | 内容 |
|---|---|
| 书桌区 | 木书桌、台灯、摊开的书和笔记本、墨水瓶和羽毛笔、一摞书、马克杯 |
| 卧室角 | 木床、被子和枕头、床头小夜灯、衣帽钩（挂伊蕾娜的帽子） |
| 墙面 | 书架、窗户（窗外是岛上夜景 / 月光）、挂画、干花 |
| 其他 | 壁炉或小火炉、地毯、橘猫（会在书桌边或床尾）、窗帘（会被风轻轻吹动） |

### 场景 3：魔法学院教室 · 上课　⬜ P1（简化版）

- **用途**：「今日课程」卡片里的上课时间段
- **镜头**：教室后排斜俯视，伊蕾娜坐在靠窗的位置
- **光照版本**：只做白天一套（上课在白天）
- **简化方案**：老师不出镜，或者只露一个背影剪影；讲课用魔法表现
- **元素**

| 类别 | 内容 |
|---|---|
| 建筑 | 原创设计的拱形窗、石墙、木梁、长条课桌 |
| 讲台 | 大黑板（粉笔自己飞起来写字）、讲桌、悬浮的魔法书（自动翻页） |
| 课桌 | 伊蕾娜的课本、笔记本、羽毛笔；前排可以放几顶空的魔女帽代表其他同学 |
| 氛围 | 窗外阳光和尘埃光束、漂浮的光点、墙上的星图 |

### 过渡：骑扫帚往返　⬜ P1

- **用途**：岛屿 ↔ 学院的切换
- **内容**：她从岛上骑扫帚起飞，飞出画面；下课后从画面外飞回来落地
