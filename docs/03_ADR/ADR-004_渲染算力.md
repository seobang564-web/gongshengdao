# ADR-004 渲染算力：云渲染平台调研后改为本地 Windows 渲染
- 状态：已接受

## 背景
Mac M1 Pro 渲染一帧夜景（25% 分辨率、8 采样）约 110 秒，完整素材约 4000 帧 2560×1440、64 采样，本机不可行。所有 .blend 是 Blender 5.2 格式，低版本打不开。

## 调研（2026-11-04 至 11-10）
| 平台 | 结论 |
|---|---|
| Render Elf | 可网页上传，但最高只支持 Blender 4.5.1 |
| 瑞云 | 必须装镭速传输工具，Mac 上一直提示「未检测到传输工具」 |
| SheepIt（免费） | 用户网络连不上 |
| 渲染101 | 官网只确认到 Blender 5.0，以 3ds Max 客户端为主 |
| 炫云 | 官网写的是 2.X |
| blender.farm / Megarender / RenderStreet / Super Renders Farm | 支持 5.2 和网页上传，但国内访问和付款方式未核实 |
| AutoDL / 恒源云等 GPU 租用 | 便宜（4090 约 1.3–2.7 元/小时），但 EEVEE 在无界面 Linux 容器里需要 EGL，可能起不来 |

## 决策
用用户自己的 Windows 电脑（NVIDIA 显卡）本地渲染。交付自包含渲染包：三个时段的 .blend（贴图已打包）+ 渲染 / 合成脚本 + 批处理，支持断点续渲，先试渲 1 帧报告耗时再全量渲染。

## 后果
- 无费用、无上传；渲染时间取决于用户显卡，需要挂机。
- 构建（建模、动画）在 Mac 上完成，渲染在 Windows 上完成，两边通过渲染包交接。
