# 前置调研 02 · 规约依据
> 对应表单「规约」一项的前置调研：验收规约里每个指标为什么这样定。规约原文见 `docs/02_规约/验收规约.md`。

| 规约 | 指标 | 依据 |
|---|---|---|
| SPEC-TT-2 课表字段识别 | 核对前字段级准确率 ≥ 85% | 印刷体表格的 OCR 本身准确率较高，误差主要来自合并单元格、单双周小字、0/O 混淆（开题报告 3.8）。识别只负责减轻录入工作，不追求一次全对，所以设 85%，真正的正确性由核对页保证 |
| SPEC-TT-6 核对后显示 | 正确率 100% | 课表错了会导致走错教室，核对后必须完全正确，这是用户能接受的底线 |
| SPEC-TT-3 周次解析 | 100% | 周次是规则解析（位图），不是概率模型，可以要求全对 |
| SPEC-TT-1 测试集 | 10 张，截图、拍照各 5 张，来自不同学校 | 覆盖不同教务系统的版式和两种输入方式；个人项目可收集的规模 |
| SPEC-SC-2/3 排程 | 200 组随机数据 0 重叠、0 差异 | 排程规则多（课程、作息、缓冲、分段、截止），手写用例覆盖不全，用随机生成 + 性质检查（不重叠、确定性）更可靠；200 组在几秒内能跑完 |
| SPEC-SC-5 不编造耗时 | 10 句全部追问 | 大模型编造的耗时会直接导致排程错误，必须零容忍 |
| SPEC-AI-1 工具调用 | 正确率 ≥ 90%，闲聊误触发 0 次 | 大模型输出有随机性，不能要求 100%；但闲聊误触发会擅自改动日程，伤害最大，所以单独要求为 0 |
| SPEC-AI-4 响应速度 | 首字中位数 ≤ 2 秒 | 流式输出下，首字出现前用户处于等待状态；2 秒内开始出字，对话体验接近即时 |
| SPEC-DS-3 背景循环 | 192 帧（8 秒）首尾无缝 | 8 秒足够容纳水面、篝火、草的多个周期，又不会让渲染量过大；循环有跳变会非常显眼 |
| SPEC-DS-4/5 片段闭合 | 首尾误差 0；循环首尾 < 1° | 片段之间要在任意时刻无缝切换，任何姿势差都会表现为「抽一下」；1° 约等于相邻两帧的正常动作幅度 |
| SPEC-DS-10 性能 | ≤ 30 fps，遮挡时暂停 | 桌面画面常驻运行，30 fps 对缓慢的环境动画足够流畅，同时显著减少显卡占用和笔记本发热 |
