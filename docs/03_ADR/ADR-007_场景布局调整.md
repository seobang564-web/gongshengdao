# ADR-007 场景布局：码头活动改到篝火
- 状态：已接受

## 背景
动作清单原计划中午在码头边晃脚、给鸭子撒面包屑。用俯视图（`evidence/island_final/island_topview.jpg`）和主镜头核对后发现：码头从门廊西北角伸进海里，在主镜头最左边缘，大半在画面外，还会被 Windows 桌面图标遮挡。

## 决策
- 中午「坐着休息」改为坐在篝火旁的原木凳上，和夜里共用「坐下 / 坐着 / 站起来」三段动作，只是光照不同；
- 「撒面包屑」改在默认站位做；
- 篝火北面被两根原木凳和栅栏围住，走路路径绕到东侧，从凳子和火之间进入；
- Mixamo 的「Sitting Idle」实际是坐在地上的动作，篝火坐姿改用「Sitting」（坐椅子）。

## 后果
- 位置集合定为：stand（门廊台阶前）、fire（篝火原木凳）、planter（门廊前花箱）、door（木屋门口）；
- 补做 4 段往返走路，保证每个位置都能回到站位。
