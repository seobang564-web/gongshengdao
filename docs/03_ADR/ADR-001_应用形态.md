# ADR-001 应用形态：Electron + Vue 3 + PixiJS
- 状态：已接受（开题报告 2.1）

## 背景
两条硬约束：① 人物和日程卡要显示在桌面上，位于壁纸之上、其他窗口之下，人物能响应点击；② 要调用 OCR 和大模型，并在本地保存课表和聊天记录。

## 调研
| 形态 | 驻留桌面 | 人物渲染 | 接入 OCR / 大模型 | 结论 |
|---|---|---|---|---|
| 微信小程序 / 网页 | 不能 | 只在页面内 | 容易 | 不满足约束 ① |
| Unity 桌面程序 | 需写原生插件 | 最强 | 网络和中文界面工作量大 | 对本项目偏重 |
| Tauri | 可以，Windows 透明窗口有已知问题 | 依赖系统 WebView，表现不一致 | 容易 | 备选 |
| Electron | 透明窗口和点击穿透接口成熟 | PixiJS / video 叠加 | Node.js 直接调用 | **采用** |

## 决策
Electron + Vue 3 + PixiJS；识别服务用本地 Python 子进程（OpenCV + PaddleOCR），通过标准输入输出传 JSON；数据存 SQLite。

## 后果
- 安装包百兆级，个人课程项目可接受。
- 同一套前端可以打包成 Wallpaper Engine 网页壁纸作为可选发布形式；聊天仍用 Electron 独立窗口（Wallpaper Engine 对键盘输入支持不可靠）。
