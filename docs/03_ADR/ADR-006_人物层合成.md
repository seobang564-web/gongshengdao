# ADR-006 人物层合成：裁剪渲染 + 比值阴影 + Workbench 遮罩
- 状态：已接受

## 背景
ADR-003 要求人物层能叠在背景循环的任意相位上，并保留人物的影子和场景遮挡（走到树、凳子后面要被挡住）。

## 备选方案
1. EEVEE 的 holdout + shadow catcher：EEVEE 5.2 没有可靠的 shadow catcher，影子会丢。
2. 整帧渲染人物片段：正确但每帧都要渲整个画面，并且片段里的背景动画和正在播放的背景循环相位不同，叠加时会错位。
3. **裁剪渲染 + 比值阴影**：
   - 人物片段只渲她附近的裁剪区域（按每个时段的太阳和点光源方向把影子范围算进去）；
   - 背景循环不含人物；场景动画全部是 192 帧周期，所以片段第 f 帧和背景第 ((f−1) mod 192)+1 帧的环境完全相同；
   - 同一帧里「有人物的画面 ÷ 没有人物的背景」= 人物投下的阴影比例，转成黑色半透明；
   - 人物本身的像素用 Workbench 遮罩（人物白、其余黑，几秒钟一帧）抠出；
   - 抗锯齿差异造成的细线假阴影用形态学开运算去除。

## 决策
选 3（`blender/island_final/scripts/render_island.py`、`compose_island.py`）。输出透明 PNG 序列和 VP9 带透明通道的 WebM。

## 证据
`evidence/island_final/compose_check.jpg`：从左到右为遮罩、人物层透明度、人物层叠洋红底、叠到另一相位背景帧上的结果。第一版有栅栏边缘的细线假阴影，加开运算后消除。

## 后果
- 夜里灯笼闪烁原来用不周期的噪声，会让比值出错 → 改为整数频率正弦叠加，严格 192 帧周期。
- 渲染时间：裁剪区域在 Mac 上没有明显加速（阴影、体积等开销是全局的），但正确性优先。
