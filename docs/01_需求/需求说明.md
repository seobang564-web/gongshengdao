# 需求说明

> 整理自开题报告《共生岛：课表驱动的大学生桌面日程与AI人物陪伴应用》（原文见 `docs/_source_开题报告.txt`）。

## 1. 产品定位
运行在电脑桌面上的大学生日程应用。三件事共用一套数据：
1. **课程表导入**：把教务课表截图 / 照片变成每天的课程卡；
2. **今日待办**：把作业、每日必做、可调整活动排进课程之间的空档；
3. **虚拟人物 AI 聊天**：用聊天录入任务、反馈进度、调课，也可以闲聊；人物在桌面岛屿场景里按日程活动。

## 2. 规模
| 维度 | 拟定规模 |
|---|---|
| 使用范围 | 个人桌面应用，一个人的一套课表、作息和任务 |
| 课表 | 每天最多 10 节课，支持单双周、间断周次和临时调课 |
| 场景与人物 | 1 套岛屿场景（另有魔法教室作为上课场景）；人物预设 2 个，同时显示 1 名 |
| AI 接入 | 文字聊天；工具调用录入任务、记录进度、调课；跨人物共享记忆 |
| 平台 | Windows 10/11 为主，macOS 为辅 |

## 3. 功能需求
### 3.1 课表导入
- 输入：课表截图或照片。预处理（透视校正、二值化）→ 表格线检测切单元格 → OCR → 字段解析（课程名 / 教师 / 周次 / 教室）。
- 周次统一解析为 20 位位图（支持 `1-16周`、`单/双周`、`1-8,10-16周` 等写法）。
- 兜底：网格检测失败 → 文字块坐标聚类 → 多模态大模型。
- 核对页：原图与识别结果对照，置信度低于 0.85、周次解析失败、同时段周次重叠时标黄，必须确认后保存。
- 教学周换算（用户只需回答"今天是第几周星期几"）、节次换算（第 5、9 节单独设置）。
- 调课用覆盖记录，不改原课表，可单独撤销。

### 3.2 今日待办
- 任务三类：课程作业（有截止）、每日必做、可调整活动；字段含预计耗时、是否可分段、单段时长范围。
- 大模型只负责把自然语言转成任务字段；时间分配由本地确定性排程算法完成（同输入同输出，可单元测试）。
- 空闲时段 = 作息窗口 − 课程 − 作息固定项 − 缓冲时间。
- 支持临时活动重排确认、进度反馈、截止风险判断。

### 3.3 AI 聊天
- 国内大模型 API；上下文拼接课表、待办、记忆；工具调用改动日程（新增任务、记录进度、调课）。
- 记忆抽取与检索，人物到期主动跟进；人设切换；异常处理与隐私（课表与聊天记录只存本机）。

### 3.4 桌面呈现
- 岛屿场景位于壁纸之上、其他窗口之下；早 / 午 / 夜三套光照随系统时间切换。
- 人物按日程和聊天切换动作（待机、走动、浇花、篝火旁坐下、挥手提醒、完成欢呼等）。
- 场景和人物用 Blender 建模，**预渲染**成 2D 素材播放，不在桌面实时渲染 3D（见 ADR-002、ADR-003）。

## 4. 非功能需求
- 桌面画面 ≤ 30 fps；被遮挡或全屏程序运行时暂停；电池供电降为静态画面。
- 聊天首字时间中位数 ≤ 2 秒。
- 课表图片与聊天记录默认只保存在本机。
