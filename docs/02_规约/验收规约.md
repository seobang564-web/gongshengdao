# 共生岛 · 验收规约

> 本文件是整个共生岛项目**最终验收时逐条检查的标准**。每条规约有编号（SPEC-模块-序号）、必须满足的行为、测试方法、通过标准和需要提交的证据。
> 需求来源见 `docs/01_需求/需求说明.md`；实现与本规约冲突时以本规约为准，修改规约需新增 ADR 说明原因。
> 状态：✅ 已通过　🟡 部分完成 / 已有证据　⬜ 未开始

## 0. 总则
| 编号 | 规约 | 通过标准 |
|---|---|---|
| SPEC-0-1 | 每条规约都必须有可复现的测试（脚本、数据集或操作步骤），证据放在 `evidence/` | 每条规约在 `evidence/` 下有对应文件或测试报告 |
| SPEC-0-2 | 同一输入两次运行，排程结果、课表解析结果必须一致（确定性） | 自动化对比 0 差异 |
| SPEC-0-3 | 课表图片、聊天记录、记忆只保存在本机；发往云端的只有当次对话需要的文字 | 抓包检查：请求体不含图片和历史聊天全文 |
| SPEC-0-4 | 核心日程功能（查看课表、待办、勾选）在断网时可用 | 断网演示通过 |
