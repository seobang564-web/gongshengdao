# Global · 项目级目标

## 一句话
做一款大学生每天打开电脑就会用的桌面日程应用：课表自动变成课程卡，作业自动排进空档，桌面上的人物用聊天陪你把事情做完。

## 目标（期末必须达到）
| 编号 | 目标 | 对应规约 |
|---|---|---|
| G1 | 一张课表截图 / 照片导入后，经核对可 100% 正确显示每天的课程 | SPEC-TT、SPEC-TM |
| G2 | 作业和每日必做能自动排进空闲时段，绝不与课程冲突，结果可复现 | SPEC-SC |
| G3 | 用聊天完成录入任务、反馈进度、调课，人物记得用户说过的计划并主动跟进 | SPEC-AI |
| G4 | 桌面上有一座随早中晚变化的岛屿，人物按日程在岛上活动，画面达到「二次元 3A」精度 | SPEC-DS |
| G5 | 打包成 Windows 安装包，演示从导入课表到完成一项待办的完整流程 | SPEC-DL |

## 不做（范围外）
- 多人 / 云同步账号体系；
- 手机端；
- 人物在桌面上自由寻路（改为预设位置之间的片段，见 ADR-003）；
- 语音聊天。

## 质量底线
- 日程数据只存本机；断网时课表和待办可用。
- 排程由确定性算法完成，大模型不直接生成时间表。
- 桌面常驻时 ≤ 30 fps，被遮挡时暂停。
