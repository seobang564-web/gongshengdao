# 观测性约定

## 1. 原则
每个有验收标准的流程都要能「看得见」：要么产生一个机器可读的检查结果（JSON），要么产生一张能人工判断的检查图。检查结果放 `evidence/`，并在 `docs/02_规约/验收规约.md` 里引用。

## 2. 自动检查指标
| 指标 | 产生位置 | 期望值 |
|---|---|---|
| 一次性片段首 / 尾与中立姿势误差 | `build_clips.py` → `closure_report.json` | 0 |
| 循环片段首尾误差 | 同上 | < 1°（不大于相邻帧动作幅度） |
| 衣摆首尾角差 | `cloth_sim` 日志 `[衣摆] ... 首尾最大角差` | 循环 ≈ 0°；一次性由首尾钉定保证 |
| 环境曲线 Cyclic 覆盖 | `build_log.txt`「补上 Cyclic 的环境曲线」 | 全部覆盖 |
| 教室遮挡检查 | `check_classroom.py` | 192 帧遮挡 0、黑板 UI 采样 63/63 无遮挡 |
| 教室规模 | `classroom_stats.json` | 三角面 < 300 万、内存峰值 < 16GB |

## 3. 渲染进度与耗时观测
- 每帧一行：`[night] B2_wave 第 12/77 帧 18.3 秒`；断点续渲跳过已存在的帧。
- 试渲（`render_island.py -- test`）输出每个片段单帧耗时和总时间估算。
- 合成日志 `compose_log_<时段>.txt`：每个片段合成帧数、视频文件、编码错误。

## 4. 视觉检查（人工）
- 白模预览：Workbench 材质色 + 阴影，在真实场景里按裁剪区域渲染，看穿模、滑步、悬空。
- 合成对比图：遮罩 / 透明度 / 洋红底 / 叠异相位背景 四联图，看假阴影和方框。

## 5. 应用阶段的观测指标
| 指标 | 采集方式 | 对应规约 |
|---|---|---|
| 聊天首字耗时（中位数、P90） | 模型调用层计时 | SPEC-AI-4 |
| 工具调用命中 / 误触发 | 测试话术集自动跑 | SPEC-AI-1 |
| 排程冲突数、确定性差异数 | 200 组随机数据测试 | SPEC-SC-2/3 |
| 课表字段准确率 | 10 张标注课表对比 | SPEC-TT-2 |
| 桌面帧率、显卡占用 | 播放器内置计数 + 任务管理器 | SPEC-DS-10 |
