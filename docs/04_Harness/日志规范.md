# 日志规范

## 1. 每个脚本都写日志文件
- 位置：和输出放在一起（`render/*_log.txt`、`island_final/build_log.txt`、`output/render_log_<时段>.txt`）。
- 格式：每行带时间（相对秒数或时:分:秒）+ 模块标签，例如 `[  17.0s] 片段 C1b_water: 135 帧 一次性 planter→planter  时段 ['morning']`。
- 必须记录：输入参数、关键中间量（位置坐标、比例 k、路径长度、裁剪区域）、每步耗时、输出文件路径、结束标记（`BUILD_DONE`、`CLASSROOM_ACCEPTANCE_PASS`）。
- 异常写完整 traceback，并继续处理下一个条目（一个片段出错不影响其他片段）。

## 2. 日志级别与内容
| 级别 | 用在哪里 | 例子 |
|---|---|---|
| 信息 | 每个步骤开始 / 结束、关键中间量、输出路径 | `[night] B2_wave 第 12/77 帧 18.3 秒` |
| 警告 | 可以继续但结果可能不理想 | `打包贴图出错`、`只有 120/192 帧，跳过视频` |
| 错误 | 某个条目失败，附完整 traceback，继续下一个条目 | `B3_cheer 视频编码出错：...` |

## 3. 不能写进日志的内容
- API 密钥、账号令牌、密码；
- 用户聊天全文、课表图片内容（应用阶段）——只记录长度、耗时、是否调用了工具。

## 4. 应用阶段（Electron）的日志约定
- 主进程、识别服务、模型调用层各写一个日志文件，按天滚动，保留 7 天；
- 每次模型调用记录：模型名、首字耗时、总耗时、是否调用工具、工具名、是否切换到备用模型。
