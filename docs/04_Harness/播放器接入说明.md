## 1. 通用规则（三个场景都一样）

### 1.1 视频规格
| 项 | 值 |
|---|---|
| 画面 | 2560×1440，24 fps |
| 背景 | H.264 MP4，**192 帧（8 秒）无缝循环**：第 192 帧接第 1 帧不跳 |
| 人物层 | WebM（VP9 + 透明通道，`alpha_mode=1`），**只有人物和她影子所在的裁剪框**，不是整幅 |
| 清单 | `clips_<场景或时段>.json`，UTF-8 |

Electron 自带的 Chromium 能直接用 `<video>` 播带透明通道的 VP9 WebM。用 PixiJS 的话，把 video 做成纹理贴上去即可。

### 1.2 画面怎么叠
```
屏幕 = 背景（整幅循环） + 人物层（贴在 x, y，大小 w × h）
```
- `x / y` 是人物层左上角在 2560×1440 画面里的像素坐标，`w / h` 是人物层视频的实际尺寸。
- 窗口不是 2560×1440 时，背景和人物层**按同一个比例**缩放：`s = 窗口宽 / 2560`，人物层贴在 `(x·s, y·s)`，大小 `(w·s, h·s)`。
- **x / y / w / h 每个片段、每个时段都不一样**（裁剪框包含影子，早上太阳低、影子长，框就大），一律从清单读，不要写死，也不要拿 Mac 上构建时的 `crop` 值。
- 人物层边缘已经做了 16 px 渐隐，贴上去不会有方框。

### 1.3 片段怎么接
- **每个一次性片段的最后一帧 = 下一个片段的第一帧**。只要按规则选下一个片段（第 6 节），直接接上就是连贯的，**中间不要加淡入淡出**（清单里标了要淡的除外）。
- **只在片段播完时切换**。循环片段（`loop: true`）在循环边界（回到第 1 帧）切。事件来了先排队，等当前片段播完再处理。
- 能不能接，看两个字段：当前片段的 `to` = 下一个的 `from`（位置），当前的 `pose_to` = 下一个的 `pose_from`（姿势，`stand` 站 / `seat` 坐）。
- `fade_out: 12` 表示片段最后 12 帧人物已经淡到透明（做进视频了），播完人物就不在画面里了，这时可以切场景。

### 1.4 背景和人物层的相位
- **岛屿**：人物层可以叠在背景循环的**任意帧**上，水面、篝火都不会错位（SPEC-DS-6 已验证）。所以背景一直循环，人物片段随时从自己的第 1 帧开始播就行。
- **魔法教室**：做法和岛屿一样，但没有专门测过任意相位。建议进教室时让背景和三个人物层都从第 1 帧开始播。
- **木屋室内**：只有 `D2_sleep` 必须和深夜背景同相位，其余片段不敏感（见木屋说明第 5 节）。

### 1.5 性能（SPEC-DS-10）
- 画面 ≤ 30 fps：素材本身是 24 fps，按 24 fps 播就满足。
- 同一时刻最多解码：背景 1 路 + 人物层 1 路（教室是 2 路），切换的那一瞬间会多 1 路。
- 被遮挡、全屏或电池供电：暂停视频，或者停在当前帧（静态画面）。

## 2. 岛屿（`clips_<时段>.json`，时段 = morning / noon / night）

### 2.1 清单格式
```json
{"time": "night", "background": "bg_night.mp4", "loop_frames": 192, "fps": 24, "resolution": [2560, 1440],
 "positions": {"stand": [x, y, z], "fire": [...], "planter": [...], "door": [...]},
 "clips": [{"name": "C3_fire_in", "time": "night", "file": "C3_fire_in_night.webm", "frames": 55, "loop": false,
            "from": "fire", "to": "fire", "pose_from": "stand", "pose_to": "seat",
            "x": 883, "y": 690, "w": 932, "h": 678, "fade_out": 0}]}
```
| 字段 | 含义 |
|---|---|
| `background` | 这个时段的背景文件 |
| `positions` | 四个站位的三维坐标，播放器**用不到**，只是给人看名字。只用名字：`stand` 门廊台阶前（默认）、`fire` 篝火原木凳、`planter` 花箱、`door` 木屋门口 |
| `frames` / `loop` | 帧数；`loop: true` 的片段循环播 |
| `from` / `to` | 起止位置 |
| `pose_from` / `pose_to` | 起止姿势：`stand` 中立站姿，`seat` 中立坐姿 |
| `fade_out` | 结尾已经淡出的帧数（只有 B4_rush 是 12） |

**某个时段的清单里只有这个时段能用的片段**，没列的就是这个时段没有。

### 2.3 位置和姿势怎么走
```
                    W_stand_planter（早）
        ┌───────────────────────────────────┐
        │                                   ▼
  ┌──────────┐                        ┌──────────┐
  │  stand   │ ◄──────────────────────│ planter  │  C1b_water（早）
  │ A1 循环   │   W_planter_stand（早）  └──────────┘
  │ B2 B3    │
  │ A3 C1a(早)│     W_stand_fire（午夜）
  │ C2b（午） │ ──────────────────────► ┌──────────────┐  C3_fire_in   ┌──────────────┐
  └──────────┘ ◄────────────────────── │ fire（站）    │ ────────────► │ fire（坐）    │
                 W_fire_stand（午夜）   │              │ ◄──────────── │ C3_fire_loop │
                                       └──────────────┘  C3_fire_out  └──────────────┘
                                              │ B4_rush（夜，结尾淡出）
                                              ▼
                                         door → 切到木屋
```
注意：
- **只有 stand 和 fire（坐）有循环片段**。planter、fire（站）都是“路过”的位置：到 planter 浇完花必须走回 stand；到 fire 站着必须坐下，或者走回去。
- **B2 / B3 只能在 stand 播**。人物在花箱或篝火时来了提醒 / 完成事件，处理方法见第 7 节。

### 2.4 事件和日程对应的片段（SPEC-DS-9）
| 触发 | 播什么 | 播完回到 |
|---|---|---|
| 时段默认（空闲） | `A1_idle` 循环；早上可以偶尔插 `A3_stretch` / `C1a_yawn` / 浇花一趟（`W_stand_planter → C1b_water → W_planter_stand`），中午可以插 `C2b_feed` | `A1_idle` |
| 日程提醒 | `B2_wave` | 原来的循环 |
| 完成一项待办 | `B3_cheer` | 原来的循环 |
| 晚上空闲（中午也有素材） | `W_stand_fire → C3_fire_in → C3_fire_loop` 循环；结束时 `C3_fire_out → W_fire_stand` | `A1_idle` |
| 截止风险（夜里） | 在篝火：坐着先 `C3_fire_out`，再 `B4_rush`，播完切木屋学习；在 stand：先 `W_stand_fire`，再 `B4_rush` | 木屋 `W_door_desk → A4_sit → B1_study` |

“偶尔插”的频率和随机方式由你们定。建议 A1 每播 3–5 圈插一次，同一个动作不要连着出现。

### 2.5 早 / 午 / 夜切换（SPEC-DS-2）
- 三个时段用的是**同一个镜头**，只换光照。切换做法：背景 `bg_<旧>.mp4` → `bg_<新>.mp4` 交叉淡化，人物层同时从旧时段版本淡到新时段版本。
- 两个版本必须是**同一个片段、同一帧**，所以只在人物处在“两个时段都有”的循环里切：
  - `A1_idle`（三个时段都有），在循环边界切，两路都从第 1 帧开始；
  - `C3_fire_loop`（午 ↔ 夜）。
- 到了切换时间，如果人物正在走路 / 浇花 / 其他一次性动作，**等她回到上面两个循环之一再切**。早上在花箱的，先 `W_planter_stand` 回到 stand。
- 三个时段的时间边界美术这边没有定，由你们按作息设置决定（比如早 = 起床到 11:00、午 = 11:00–17:00、夜 = 17:00 到睡觉，这只是建议）。

## 4. 木屋室内（`clips_cabin.json`）：学习、睡觉、起床

完整说明见 [`木屋室内接入说明.md`](木屋室内接入说明.md)。和岛屿不同、最容易漏掉的有四点：

1. **背景跟着片段走**，不是按时段固定：读 `clip["views"][机位]["background"]`，人物层的位置也从同一个对象里读。换背景时**背景帧号要连续**，不要从头播。
2. **书桌有两个机位**（`E_monitor` / `A_right34`）：`B1_study`、`B6_smile` 读 `views`，只在 B1 的循环边界切换机位。
3. **木屋里完成待办播 `B6_smile`**（`trigger: "task_done"`），不是岛上的 `B3_cheer`。要等 B1 回到第 1 帧再播，播完接回 B1；连续完成多项就排队。
4. **`D2_sleep` 的淡入淡出由播放器做**（`fade_mode: "player"`，各 12 帧），而且 D2 必须和 `bg_cabin_late.mp4` 从同一帧开始、一起循环。其它带转场的片段是 `"baked"`，已经做进视频了。

木屋流程：`W_door_desk → A4_sit → B1_study 循环（完成待办插 B6_smile）→ A4_up → W_desk_bed（淡出）→ D2_sleep 循环 → W_bed_window（淡入）→ G6_curtain → W_window_hat → G5_hat → W_hat_door（淡出）`。

木屋只有**夜里**（学习）、**深夜**（睡觉）、**清晨**（起床）三套光照。

## 5. 三个场景串成一天

```
 早上（清晨木屋）  W_bed_window … G5_hat → W_hat_door（淡出）
        │ 切到岛屿（早）
        ▼
 岛屿·早   A1_idle 循环，插 A3 / C1a / 浇花；提醒 B2，完成 B3
        │ 到上课时间 ──────────────► 魔法教室：B5 + T1/T2，下课回岛屿
        ▼
 岛屿·午   A1_idle，插 C2b；可去篝火坐
        ▼
 岛屿·夜   空闲：去篝火坐 C3；提醒 / 完成照常
        │ 开始学习任务 / 截止风险（B4_rush 淡出）
        ▼
 木屋·夜   W_door_desk → A4_sit → B1_study（完成待办 B6）
        │ 到睡觉时间
        ▼
 木屋·深夜 A4_up → W_desk_bed → D2_sleep 循环
        │ 到起床时间
        └──► 回到最上面
```

切场景的方法：
- 当前片段已经淡出（`fade_out` / `fade_mode: baked` 结尾），人物不在画面里，这时把背景换成新场景，可以加 12–24 帧交叉淡化。
- 新场景第一个片段自带淡入（木屋的 `W_door_desk`、`W_bed_window`）就直接播。不带淡入的（岛屿 `A1_idle`、教室 `B5_listen`），由**播放器把人物层透明度从 0 拉到 1**，用 12 帧（见第 7 节）。

## 6. 状态机建议

**优先级：事件 > 日程状态 > 时段默认**（ADR-003）。只在片段播完、或者循环到边界时切换。

```text
每一帧：
  推进背景（循环）和当前人物片段
  if 当前片段播完 或 (当前片段是循环 且 刚回到第 1 帧):
      下一个 = 选下一个片段()
      要求 下一个.from == 当前.to 且 下一个.pose_from == 当前.pose_to
      从第 1 帧开始播 下一个

选下一个片段():
  1. 事件队列不为空（提醒 / 完成 / 截止风险）：
        如果当前位置、姿势能直接播对应片段（例如在 stand 播 B2），就播它，然后回到原来的循环
        否则先找一条路走过去（例如坐着 → C3_fire_out → W_fire_stand → stand），
        或者按第 7 节兜底
  2. 日程状态变了（上课、学习、睡觉、起床、晚上空闲）：
        按第 5 节的路线一段一段走过去（先回到可以离开的位置，再切场景）
  3. 时段该切换了：只在 A1_idle / C3_fire_loop 的循环边界切（第 2.5 节）
  4. 都没有：继续当前循环，或者按概率插一段空闲动作
```

实现上的建议：
- 用两个 `<video>`（或两个纹理）交替：当前片段快播完时，提前把下一个片段加载到另一个元素上、停在第 1 帧；当前片段一结束马上切过去，这样不会闪黑帧。
- 片段之间是按帧对齐的。用 `requestVideoFrameCallback` 或者按 `currentTime` 判断“播完”，不要依赖 `ended` 事件后再去加载。
- 做一个调试面板，可以手动触发每种事件、切换时段，验收 SPEC-DS-9 时要用。

## 7. 现在缺的过渡片段，播放器先怎么兜底

下面这些情况现在**没有对应的动作片段**。播放器先按右边的办法处理；需要真正的动画时，告诉美术对话来补。

| 情况 | 缺什么 | 播放器先这样做 |
|---|---|---|
| 从木屋回到岛屿早上 | 门口 → stand 的走路 | `W_hat_door` 淡出后切到岛屿，`A1_idle` 人物层由播放器 12 帧淡入 |
| 平时（不是截止风险）开始学习 | 岛上 stand → 门口的走路 | `A1_idle` 播完一圈后由播放器 12 帧淡出人物，切到木屋播 `W_door_desk`（自带淡入） |
