# 开发规范

## 1. 环境
| 用途 | 环境 |
|---|---|
| 建模、动画构建 | macOS（M1 Pro 16GB），Blender 5.2 |
| 正式渲染 | Windows 10/11 + NVIDIA 显卡，Blender 5.2 |
| 应用开发（下一阶段） | Electron + Vue 3 + PixiJS，Node.js；识别服务 Python（OpenCV、PaddleOCR），SQLite |

- 所有 .blend 是 Blender **5.2** 格式，4.x 打不开；不要用低版本保存覆盖。
- Blender 场景一律**无界面运行**：`blender -b [文件.blend] -P 脚本.py -- 参数`。在 GUI 里构建完整场景会占用约 32GB 内存并卡死；GUI 只用来查看，视口保持 SOLID。
- 需要从 GUI 触发时，在 Python 控制台用 `subprocess.Popen([bpy.app.binary_path, "-b", ...])` 起后台进程（见 `blender/_launch.py`）。

## 2. 目录
见根目录 README。新脚本按用途放：场景 → `blender/`，岛屿最终版流水线 → `blender/island_final/`，教室 → `blender/classroom_parts/`；生成的 .blend、渲染帧、视频不进仓库。

## 3. 素材规格（所有场景、动作都遵守）
| 项目 | 规格 |
|---|---|
| 分辨率 / 帧率 | 2560×1440，24fps |
| 循环片段 | 8 秒 = 192 帧，第 193 帧 = 第 1 帧；环境动画曲线全部加 Cyclic，周期 192 帧 |
| 一次性片段 | 从「中立站姿」（站立待机第 1 帧）开始并结束；坐姿片段以「中立坐姿」（坐着循环第 1 帧）衔接；首尾 12 帧过渡 |
| 镜头 | 正交斜俯视：方位角 −28°，仰角 42°，正交尺寸 24；室内用「去掉两面墙的剖面小屋」 |
| 引擎 | EEVEE，64 采样，光追和体积开启，AgX + "AgX - Punchy"，合成器 Glare(Bloom) |
| 视图层 | BG / FG（前景遮挡）/ CHAR；集合名 BG_*、FG_前景遮挡、CHAR_人物、LIGHTS_灯光 |
| 人物 | 「二次元 3A」精度，不做 Q 版；袖口始终下垂（反向补偿）；斗篷物理摆动 |
| 光照时段 | morning / noon / night |

## 4. 命名
| 对象 | 规则 | 例子 |
|---|---|---|
| 人物片段 | `<编号>_<动作>`，编号对应动作清单 | `B2_wave`、`C3_fire_loop`、`W_stand_fire`（W = 走路） |
| 片段动作数据 | 骨架动作 `CLIP_<片段>`，根节点动作 `CLIPR_<片段>` | `CLIP_B2_wave` |
| 输出 | `bg_<时段>.mp4`、`<片段>_<时段>.webm`、`clips_<时段>.json` | `B3_cheer_night.webm` |
| 教室物体 | 前缀 `cls_` | `cls_board_ui` |
| 位置 | `stand` / `fire` / `planter` / `door` | |

Mixamo 动作文件（放在 `动作/`，不进仓库）：Arm Stretching、Breathing Idle、Happy Walk、Jogging、Joyful Jump、Laying Sleeping、Lying Down、Sit To Stand、Sitting Idle、Sitting、Sitting_edge、Stand To Sit、Thinking、Throwing、Typing、Victory Idle、Watering、Waving、Yawn（均为 FBX，24fps，With Skin 关闭）。

## 5. 片段清单 JSON（交给播放器）
```json
{"time": "night", "background": "bg_night.mp4", "loop_frames": 192, "fps": 24, "resolution": [2560, 1440],
 "positions": {"stand": [x, y, z], "fire": [...], "planter": [...], "door": [...]},
 "clips": [{"name": "C3_fire_in", "file": "C3_fire_in_night.webm", "frames": 55, "loop": false,
            "from": "fire", "to": "fire", "pose_from": "stand", "pose_to": "seat",
            "x": 820, "y": 600, "w": 932, "h": 678, "fade_out": 0}]}
```
x / y 为人物层在 2560×1440 画面中的左上角像素坐标。

## 6. 分支与提交
- `main` 始终可运行；较大的改动开分支，完成后合并。
- 提交信息：`<类型>(<范围>): <说明>`，类型用 feat / fix / docs / test / chore / refactor，例如 `feat(cloth): 斗篷相邻链拉平`。
- 提交前：脚本能无界面跑通；改了动画就重跑闭合检查（`build_clips.py` 会输出 `closure_report.json`）。
- 不提交：.blend、.blend1、渲染帧、视频、压缩包、人物模型和 Mixamo 原始文件（见 .gitignore）。
