## 镜头与分层
- 渲染镜头 `CAM_side_back`：伊蕾娜右后方近景（透视 26 mm）。
- 三层：空教室背景 192 帧循环 / 伊蕾娜层（B5_listen）/ 老师层（T1_lecture 循环、T2_pace 一次性）。渲一层时另一层隐藏。
- 清单 `clips_classroom.json` 每个片段多了 `layer` 字段（elaina / teacher），桌面端按两层分别播放。坐标：B5 (139,751,996,688)、T1 (1188,216,930,742)、T2 (671,271,1730,692)。
- 老师层切换：T1 循环；T1 播完一圈后可切 T2，T2 播完回 T1（首尾同一姿势）。

## 文件（`blender/classroom_anim/`）
- `build_classroom.py`：开 magic_classroom.blend → 追加伊蕾娜、B5_listen → exec `board_chalk.py`（板书）→ exec `teacher.py`（老师导入、配色、重定向、T1/T2）→ 存 `classroom_anim.blend` → Workbench 白模。环境变量 `GSD_STILLS=1` 时先出 3 张 EEVEE 静帧。
- `teacher.py` 要点：MMD 骨架映射（腿用 足D/ひざD/足首D），骨架原点偏 0.74 m 已对正到 センター；站姿收腿 65%、髋部去水平平移、腰上身晃动压到 25%；教鞭朝向按身体坐标系（站竖握 / 走路斜向前下 / 指黑板顺手臂），挂在 手首.R。
- `pack_classroom.py`：删老师模型隐形叠加层（T_hidden 材质的面）→ 算裁剪框（网格投影 + 80 px 边距）→ 写清单 → 打包贴图 → `winpkg_build/classroom.blend`。
- `scripts/render_classroom.py`、`scripts/compose_classroom.py`：由岛屿脚本改成多层；遮罩排除 dust / shaft / volume（教室光尘 `cls_dust_*`）。
- `winpkg/`：Windows 批处理 + 说明.txt。
- 老师模型：`characters/teacher/Untitled.fbx`（版权素材，不进 Git）。
- 证据：`evidence/classroom_anim/`（构建 / 打包 / 渲染 / 合成日志、片段清单、成品检查报告、遮罩修复前后对比、成品抽帧）。
