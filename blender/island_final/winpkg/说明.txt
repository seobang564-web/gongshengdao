共生岛 · 岛屿最终版 · Windows 渲染包
=====================================

【准备】
  · Windows 上装好 Blender 5.2（必须是 5.2，4.x 打不开），NVIDIA 驱动更新到最新。
  · 把整个文件夹解压到不含中文的路径，例如 D:\gsd_island\
  · 不需要另外装 ffmpeg，视频用 Blender 自带的编码器生成。

【使用方法】（双击运行，按顺序来）
  0_test_one_frame.bat   每个时段、每个片段各渲 1 帧成品，日志最后会写出估算的总时间。
                         看 output\bg_night\ 和 output\raw\ 里的图片，确认画面正常（人物不是粉色、没有发黑）。
                         试渲的帧是成品质量，后面正式渲染会直接沿用，不会重复渲。
  1_render_night.bat     渲夜晚：背景循环 + 9 个人物片段 + 遮罩，然后自动合成视频。
  2_render_morning.bat   渲早晨（8 个人物片段）。
  3_render_noon.bat      渲中午（9 个人物片段）。
  4_render_all.bat       夜 → 早 → 午 全部依次渲染（适合整晚挂机）。
  5_compose_only.bat     只重新合成视频（渲染已经完成时用）。

  · 中途关掉了，重新双击同一个 .bat 会跳过已经渲好的帧，接着往下渲。
  · 如果提示找不到 Blender，用记事本打开 _find_blender.bat，把 BL= 后面改成你电脑上 blender.exe 的完整路径。
  · 爆显存（out of memory）或画面发黑，把 output\render_log_*.txt 和截图发给我。

【输出】在 output\video\ 里：
  bg_night.mp4 / bg_morning.mp4 / bg_noon.mp4      背景循环（不含人物），2560×1440，8 秒，首尾无缝
  <片段>_<时段>.webm                                人物透明视频（VP9 带透明通道），只有人物附近的一块画面
  preview_<片段>_<时段>.mp4                         预览：人物叠在背景上的效果（半尺寸，方便检查）
  clips_<时段>.json                                 片段清单：每段的帧数、是否循环、起止位置、在画面里的位置 x/y/w/h
  另外 output\layer\ 里是透明 PNG 序列（和 webm 内容相同，备用）。

【在壁纸里怎么用】
  背景视频循环播放；人物 webm 按 clips_*.json 里的 x、y 放到画面对应位置（左上角为原点，单位像素，基于 2560×1440），
  叠在背景上面。人物层可以在背景的任意时刻开始播放，水面、篝火、草的动画不会错位。
  所有一次性片段都从「中立站姿」开始、回到「中立站姿」结束；篝火旁的三段以「中立坐姿」衔接，
  所以只要在一个片段播完时再切下一个，画面就是连续的。

【片段清单】
  位置：stand = 门廊台阶前的默认站位；fire = 篝火旁原木凳；planter = 门廊前的花箱；door = 木屋门口
  A1_idle          站立待机（循环 192 帧）                         早 / 午 / 夜
  B2_wave          提醒挥手                                        早 / 午 / 夜
  B3_cheer         完成欢呼（开心跳 + 举手欢呼）                    早 / 午 / 夜
  A3_stretch       伸懒腰                                          早
  C1a_yawn         打哈欠                                          早
  W_stand_planter  走到花箱                                        早
  C1b_water        浇花                                            早
  W_planter_stand  从花箱走回站位                                  早
  C2b_feed         撒面包屑                                        午
  W_stand_fire     走到篝火旁                                      午 / 夜
  C3_fire_in       坐到原木凳上                                    午 / 夜
  C3_fire_loop     坐着（循环 192 帧；中午是休息，晚上是烤火）      午 / 夜
  C3_fire_out      站起来                                          午 / 夜
  W_fire_stand     从篝火旁走回站位                                午 / 夜
  B4_rush          截止风险：从篝火旁小跑回屋（最后 12 帧淡出）     夜

  切换示例（晚上）：A1_idle → W_stand_fire → C3_fire_in → C3_fire_loop（循环）→ C3_fire_out → W_fire_stand → A1_idle
  人物在 fire 位置站着时要提醒：C3_fire_out 之后 → B4_rush（截止风险）或 W_fire_stand。

【技术说明】
  · 人物只渲染她附近的裁剪区域（包括影子），场景、光照、描边和背景完全一样；
    合成时用「有人物的画面 ÷ 背景」算出人物投下的阴影，再用遮罩抠出人物，得到透明人物层。
  · 斗篷带物理摆动（会滞后、被腿顶开），所有片段的衣摆首尾都和相邻片段对齐。
  · 伊蕾娜出自《魔女之旅》，仅用于非商业课程演示，请勿公开发布。
